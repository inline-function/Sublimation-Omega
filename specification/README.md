# specification/ — 重构规范

本目录是重构工程的**约束性规范**：重构后的系统"必须是什么样"，以这里为准。
它存在的目的只有一个——**防止跑偏**。

## 效力

1. 代码与本目录冲突时，以本目录为准；要改的是代码，不是规范
2. 修订规范必须显式留痕：注明日期与原因，禁止悄悄改动
3. 工人任务书只能引用本目录的条款编号，禁止引用对话记忆——对话会失传，规范不会

## 与 documents/ 的分工

| 目录 | 性质 | 回答的问题 |
| --- | --- | --- |
| `specification/` | 规范性——**必须如此** | 系统该是什么样？ |
| `documents/idea documents/` | 记录性——**为何如此** | 当时为什么这样决定？ |
| `documents/log/` | 编年性——**当时如此** | 当时发生了什么？ |

动机记进理念文档，过程记进日志，**约束写在这里**。

| P-9 | **语言简化（已拍板 2026-11-06）**：①删 `enum`，改「多个 struct + `type E = A \| B` 联合别名」，联合支持**一切类型表达式**；②删 `def`（命题可由 `axiom` 直接引入，未被定义的命题名可按原子使用）；③删 `val`（只保留 `var`；`var` 不得在顶层声明、不得在 class 体内声明——**脚本模式下允许顶层 var**；class 不能携带状态）；④函数形参与 struct 字段均可带默认值，但**类型标注不得省略**，默认值只能引用**先于它声明**的参数/字段；⑤`when` 分支箭头统一为 `->`（消 `is (Nat)=>Nat => 2` 的二义性）；⑥空构造子为**全局唯一单例**，声明可省括号、**不得用 `X()` 构造**；⑦归纳类型别名（如 `type Peano = Zero \| Succ[Peano]`）合法并落补充级诊断 `D-INDUCTIVE-TYPE`，非归纳自引用报 `E-CYCLE`；⑧遮蔽规则：顶层名唯一，局部允许后遮蔽前（含**局部扩展函数**），扩展函数按 (接收者头, 名字) 判重。规范性内容见文法卷附录 B 与 ADR-24~ADR-30 | 🟢 已拍板 |
