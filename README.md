# Sublimation

声明式设计验证语言（受 Rust / Kotlin 启发）：**写程序 = 写命题 + 写实现**，编译器验证两者一致。

> [!NOTE]
> 本仓库是 Sublimation 编译器的**重构工程**，当前处于架构设计阶段。
> 旧实现位于 `F:\KotlinProject\sublimation`，仅作历史参考。

## 编译管线

```
词法集 → 抽象语法树 → 高级语义树 → 低级语义树 → 产物
```

| 阶段 | 职责 |
| --- | --- |
| 词法集 | 源代码的线性 token 序列 |
| 抽象语法树（AST） | 纯语法结构，零语义 |
| 高级语义树 | 语义分析、类型推导与证明检查的家园 |
| 低级语义树 | 降级后的核心表示，后端的唯一入口 |
| 产物 | 低级语义树经后端生成的目标代码（JS、……） |

## 重构原则

1. **文档是意图规格**——语言"应该"是什么样，以文档为准
2. **旧测试是行为规格**——旧实现的 530+ e2e 回归是验收底线
3. **旧代码是字典**——只在文档含糊时点查，禁止通读
4. **一次只动一个大件**——本次只重构架构，实现语言保持 Kotlin
