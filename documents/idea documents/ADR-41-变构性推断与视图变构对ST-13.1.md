# ADR-41：变构性自动推断与视图变构对（ST-13.1）

> 状态：已落地 · 日期：2026-11-08 · 前置：ADR-39（t62 子类型偏序，同名同参逐参协变子句）、ADR-38（t61 视图降级）、ADR-37（t60 造格位核对）
> 来源：**用户裁决（2026-11-08，逐字）**——「类型参数的变构性推断看它的使用位置。如果只在函数参数上使用，则是逆变；如果只在返回类型以及**不可变属性**上，则是协变；如果又协变又逆变，就自动推断为不变。如果**在所有的非 @mut 函数里都是协变位，但是在 @mut 函数里有逆变位的使用**，则认为这个类型参数在类型没有 @mut 的时候是协变，在有 @mut 的时候是不变。」
> 范围：新增 VarianceInfer.kt（推断器）+ compileVariance 观察入口；Elaborator theoryParam 升级（双视图极性）；TypeInfer 同名同参应用按声明变构分派 + @mut 借用「视图对视图」；测试 VarianceInferTest 31 例。**判官主体/偏序其余子句/减法/燃料/深度哨/轮次一律未动**。

## 一、缺陷与根因（BEFORE 证据）

队长实测 5 条「泛型实参位变构」探针，**全部通过**——含三条本该拒绝的（2026-11-08）：

| # | 形态 | 应有 | 实测 |
|---|---|---|---|
| w1 | Sink[Any] 传 Sink[Nat] 位 | 通过（逆变正方向）| ✅ |
| w2 | Sink[Nat] 传 Sink[Any] 位 | 拒绝 | ❌ 通过 |
| w4 | Box[Any] 传 Box[Nat] 位 | 拒绝 | ❌ 通过 |
| w5 | Both[Nat]/Both[Any] 互传 | 拒绝（不变）| ❌ 通过 |

根因（队长给线索、本任务实测确认）：TypeInfer.sub 中 `want is HirNamedType && traitSubtype != null && traitSubtype!!(got, want.name) -> true` **只比特质名字、不比类型实参**，且位于「同名逐参协变」子句**之前**——Sink[Nat] <: Sink[Any] 经父链（Sink→Sink，自名命中）直接放行，实参位从未被核对。此外，变构性本身全前端**不存在**（无表、无 σ_imm/σ_mut）——用户裁决无处落地。

## 二、算法（VarianceInfer）

**格**：双变 > {协变, 逆变} > 不变；meet 为交。每个声明（trait/struct）的每个类型参数维护 (σ_imm, σ_mut) 两个格值。

**使用处收集**（sitesOf）：
- 特质父链类型：正位，两视图皆计。
- 成员：**@mut 接收者成员的全部使用位（返回位 + 形参位）只在 σ_mut 计**——不可变视图无法调用 @mut 方法，其返回类型在 imm 视图不可观察（这一条是 R5 对称例推导出的必要口径：fun put(x: T) + @mut fun grab(): T ⇒ (逆变, 不变)，亦使 R4 例 imm=协变 正确）；非 @mut 成员：返回位正、形参位负，两视图皆计。
- 结构体字段：不可写字段读位（正，两视图）；**可写字段（mut 注解）读 + 写（−）同时计，贯通两视图**——任意不可变值经造格即可得 @mut 视图，写字段毒化 imm 视图（验收 #5 (不变, 不变)）。

**复合极性**（ST-12）：类型游走沿应用链乘因子——G[args] 处每个实参位的极性 × G 对应参数的当前格值（负×负=正；×不变 ⇒ 不变；×双变 ⇒ 不约束，见下）；(T) => U 形参位翻极性；联合/元组保持极性；@mut X 包装内置 underMut（应用因子取 σ_mut 而非 σ_imm）。

**不动点**（3.2）：初值双变 → 全仓各声明单调 meet（逐步降级）→ 不动点。格高度 2 ⇒ 每轮每参数至多降一级，跨声明传播深度每轮加深一层 ⇒ 必然收敛（Tree 自引用、A↔B 相互递归测试实测收敛，验收 #6/#7）。**轮次上限 16**，超出落 `E-VARIANCE-NOFIXPOINT`（明确码与文案，不静默取默认）。未用参数定案**协变**（格值保持双变 → 协变；幻影参数不约束实参型）。乘因子时双变按协变处理（未用参数的嵌套出现不约束外层——否则自引用参数永远卡在双变）。

**HKT（V1 简化）**：F[X]（F 为自身高阶参数）贡献**极性本身**（不做参数槽的二次复合）；trait A[F[_]] : B[F] 父链里 F 作实参仍乘 B 的格值。

**内建硬表**（BuiltinVariance）：List/Optional/Result/Set/Flow/Range/Tuple ⇒ (协变, 不变)；Map ⇒ (不变,不变) K + (协变,不变) V。内建泛型**不进一般推断管线**——varianceOf 先查用户声明表（同名覆盖），次取硬表，未知 → null（调用方回退旧口径）。

**单调性机械自检**（3.4c，硬要求）：推断收口时对全仓每个声明每个参数断言两部律，违反落 `E-VARIANCE-MONO`（视为实现 bug）；VarianceInferTest.mono_* 另以**测试代码**对 e2e 全套 68 样本 + 全部 fixture 逐声明机械断言（σ_imm=不变 ⇒ σ_mut=不变；σ_mut=协变 ⇒ σ_imm=协变）。构造上 σ_mut 的贡献集 ⊇ σ_imm 的贡献集（视图划分 + 可写字段贯通），meet 更严 ⇒ 两部律恒成立（逻辑论证 + 机械断言双证）。

## 三、与 ST-13.1 的逐条对齐

| 用户裁决 / ST-13.1 | 落地 |
|---|---|
| 只在函数参数上 ⇒ 逆变 | #2 Sink (逆变, 逆变)；w1/w2 子类型按逆变分派 |
| 只在返回类型 + 不可变属性 ⇒ 协变 | #1 Box (协变, 协变)；#3 之协变对照（r5b 不可写字段） |
| 又协变又逆变 ⇒ 不变 | #3 Both (不变, 不变)；#8 E-BOUND-INVARIANT 不回退 |
| 非 @mut 全协变 + @mut 有逆位 ⇒ (协变, 不变) | #4 List (协变, 不变)（R4 核心例）；σ_mut 在 @mut 视图子类型生效（m1） |
| 对称情形 ⇒ (逆变, 不变) | 对称例 r4c（put 形参位 + @mut grab 返回位）⇒ (逆变, 不变) |
| 可写字段（读 + / 写 − 同时计）| #5 (不变, 不变)（r5 + 对照 r5b） |

## 四、语义接入（sub 分派，队长 w1~w5 验收点）

新增子句**位于特质满足子句之前**（根因修复）：

```
got/want 同名同参（实参非空）⇒ 逐参：σ_imm 协变 → sub(a,b)；逆变 → sub(b,a)（反向）；不变 → typeEq；无表 → 约定协变（t62 旧口径回退）
```

@mut 双视图：clause 5（got @mut && want @mut）内层同名同参应用按 **σ_mut** 同口径分派（无表回退 typeEq，t61 旧口径）。造格/借用 6 位（var/赋值/默认值/形参/ctor 实参/structCtor）由「降级 want」改为 borrowView(got, want)：**got 已是 @mut 视图时视图对视图比对**（@mut 视图不变性经分派生效），否则降级 want（ST-11.1 旧口径不变）。

效果（实测，负正成对）：w2/w4/w5 转为**拒绝**；w1/w3 保持**通过**；m1（@mut List[Nat] → @mut List[Any] 位）拒绝；m2 同型通过、m3 imm 视图协变升宽通过；对照 w6（内建 List imm 升宽）、w7（父链满足）、b4（未知名回退）不回归。

## 五、不动点收敛证据

- 格高度 2：每轮每参数至多降一级；跨声明应用因子每轮加深一层传播；全仓声明数有限 ⇒ 收敛轮数 ≤（依赖深度 + 1）。
- 实测：Tree[T] { children(): List[Tree[T]] }（#6）与 A[T] { toB(): B[T] } / B[T] { toA(): A[T] }（#7）均收敛且无 E-VARIANCE-NOFIXPOINT。
- e2e 全套 68 样本的 mono_fullE2eCorpus 实测：0 个 NOFIXPOINT、0 个 MONO、逐声明两部律全过。

## 六、内建边界与守卫（延迟项声明）

内建泛型走**独立硬表**（本任务锁死 (协变, 不变)），理由与守卫：
- 依据：List/@mut List 是内建/prelude 形态（用户样本里的 type List[T] = Nil | Cons[T] 是**别名**，不在变构表内——别名经既有别名展开位/内建回退处理）；硬表的 @mut 不变性由 ST-13.1 的视图不变性裁决直接给定，不经使用处推断。
- 守卫证据（测试）：b1/b2 锁死无用户声明时内建 (协变, 不变) 的两视图行为；b3 断言**用户同名声明覆盖硬表**（用户纯协变 List 的 @mut 视图按用户表协变接受）——「不得被一般推断覆盖」即「硬表不得吞掉用户声明」，反之亦然。
- 推迟到步骤 4：内建表与字典/统一类型源的归并；σ_imm ≠ σ_mut 时界方向的视图化处理。

## 七、步骤 4 衔接（界方向判定）

- 声明位界方向由 σ_imm 决定（#9 逆变 ⇒ 下界方向、#10 返回位协变 ⇒ 上界方向）：**方向已由 VarianceInfer.sitesVariance 判定**（每声明每参数内部可查，compileVariance 暴露）；E-BOUND-INVARIANT（σ_imm 不变 + 界）保持 t62 行为不回退（#8 实测落码）。
- **边界声明**：下界方向的**调用点强制**（字典/解选择）随步骤 4 落，本轮只保证 σ_imm 路径正确——#9/#10 声明位通过（任务书「若当前无法取得期望值须报告」，不在 V1 落诊断伪造完整界语义）。
- compileVariance（Semantic.kt）为工具/测试观察入口，生产路径仍是 compile（HIR 结构未改，快照零影响）。

## 九、V1 简化与已知限制

1. HKT F[X] 贡献极性本身（不做参数槽二次复合）；2. 未用参数定案协变（幻影）；3. 别名不在变构表（别名比较经别名展开位 + 内建回退）；4. 函数级界方向未入 HIR（步骤 4 处理）；5. 父链极性视作正位（特质继承为协变扩张，V1）。
