# ADR-62:D-12 模式真值单源化（scriptMode 透传,废两处自算）

| 状态 | 口径 |
|---|---|
| 已接受（2026-11-11,队长代码审查发现 + 处决令）| D-12 缺陷修复;CLI 真值为唯一源 |

## 背景

模式（project / script）真值在三处各算一遍,且两处自算互相继承同一缺陷:
- **Main.kt:46**(CLI):`scriptMode = opts.script || unitPath.endsWith(".subs")` —— 唯一有资格的源头;
- **Frontend.kt:41**:`compile(pr.file, pr.notes)` 丢弃了上面算出的真值;
- **Elaborator.kt :578**(自算):`scriptMode = f.entries.any { it is StmtEntry }`;
- **HirJson.kt :187**(`unitMode`):`hir.entries.any { it is HirStmtEntry }`。

缺陷:**工程模式允许顶层 axiom 语句落 StmtEntry**(Parser:204),自算把「有条目⇒脚本」当判据 ⇒
`公理化.subl` 顶层 `axiom moduleReady` 被误标 script(elaborator 补法分立与 envelope 双错——
t99 基线 envelope 已带病:mode="script")。

## 决策（处决 1-4)

1. **签名加参一路透传**,默认值 = project:
   - `Semantic.compile(file, parseNotes, scriptMode: Boolean = false)`;
   - `elaborate(..., scriptMode, varianceSink)` 及 `elaborateNarrow/elaborateWithVariance/
     elaborateWithNarrowAudit` 同参透传;`Elaborator` 私有 ctor `val scriptMode: Boolean` 成员;
   - `Frontend.compileFrontend(source, unitPath, scriptMode: Boolean = false)`(分派 parseScript /
     parseSource + compile + emit);
   - `HirJson.emit(hir, diag, unitPath, scriptMode: Boolean = false)` 与 `writeTo` 同参。
2. **废除两处自算**:Elaborator 删 `val scriptMode = f.entries...`;HirJson 删 `unitMode` 函数。
   envelope.mode 与补法分立（隐式 _ / 脚本宽待）全部读透传真值。
3. **纯度闸同源**:`runPurityGate` 的脚本顶层非纯 scope 由 `if (scriptMode)` 推入
   （原 `hir.entries.any { is HirStmtEntry }` 自算同步废除）。
4. **边界验真**（CLI 直编实测,Main.kt:46 真值）:
   - `t.subs` 默认 → mode=script; `t.subl` 默认（含顶层 axiom）→ mode=**project**（修复生效）;
   - `t.subl --script` 显式覆盖 → mode=script;
   - `compileFrontend` 函数层**不嗅探扩展名**——真值只从调用方传入（杜绝第二真值源;T111 回归锁定）。

## 后果与边界

- 模式真值从此单源:CLI(Main.kt:46)→ compileFrontend → compile → Elaborator / HirJson。
  下游 R-02 通道与 t108 的 unit.mode 核对有了可信地基（处长令:此处不得留坑）。
- `compile()` 公开 API 默认 project:库式调用者（含旧测试）默认工程严判;脚本用例显式传
  scriptMode = true。ParseResult/Parser 层的 scriptMode 分派（parseScriptSourceWithNotes 等）不动——
  CLI 层选好解析器后同参透传。
- 夹具适配均为**旧自算判据的锚定改写**,非行为回退;T111ModeTruthTest 4 例锁定真值单源红线
  （工程 axiom → project / --script 覆盖 / 函数层不嗅探扩展名 / emit 默认 project）。
