# ADR-45 反引号标识符放开：任意字符含裸换行

**日期**：2026-11-08（t68，用户 17:0x 裁决）
**状态**：已落（B1-B5 全部规则化）

## 一、决策

反引号标识符放开为**任意字符（含裸换行）**的单 token:

| # | 规则 | 实现 |
|---|---|---|
| B1 | 内容任意：结构字符 `( ) [ ] { } , ; . @ \ # "`、ASCII 符号、CJK、空格、**裸换行** | `readBacktickIdent` else 分支原样 append（`\n` 进名字，行号随 `adv()` 推进） |
| B2 | 唯一转义 `\`` = 字面反引号 | `c == '\\' && i+1 < len && src[i+1] == '\\`'` → append('`') |
| B3 | 反引号不进名字：`` `foo` `` ≡ `foo` | 既有（名字=去反引号内容）；重复声明照常 E-DUP-DECL |
| B4 | 单/多空格为合法名字且互不相同 | 既有 else 分支 append 空格；B1 不排斥 |
| B5 | 空反引号 ⇒ 新码 `E-BACKTICK-EMPTY` | `LexError` 新增 `code: String = "E-LEX"` 字段，空名位传 `E-BACKTICK-EMPTY` |

CR 不进名字（CRLF 行尾与字符串口径一致）。转义仅 `\`` 一种：`\n` 字面进名字（两字符），
符合「唯一转义」的严格读法。

## 二、三处实现细节

1. **行列计数**：裸换行使 token 跨行——`adv()` 在 `\n` 时 `line++/col=1`,token 记**起始**行/列（`tokens()`
   的 `sl/sc`);词法诊断一律 `(sl, sc)` 起始位置（既有约定延续）。诊断指向起始行由测试 #5 断言（未声明
   `E-UNBOUND-NAME` 落 token 起始行）。
2. **HIR/JSON 转义**:`JsonWriter.escapeJsonString`（既有）已覆盖 `\" \\\\ \b \t \n \f \r` 与 `< 0x20` 的
   `\uXXXX`,含换行的名字发射即合法 JSON——测试 #8 断言 `"x\\ny"` 转义形态存在且字符串值内无裸换行。
   本 ADR 未改 json 包。
3. **`precededBySpace` / 同行判定**：D-5 中缀糖依赖「前后带空格且同行」;跨行反引号 token 的 `cur().line`
   是起始行，其后的 token 在别的行 → 同行判定自然失败 → **中缀糖不跨行成立**（无需额外代码）。

## 三、实现坑：peekAt 是绝对索引

首版转义分支写成 `c == '\\' && peekAt(1) == '\\`'`——`peekAt(j)` 返回 `src[j]`（**绝对偏移**，非
`src[i+j]`),分支恒不命中。症状极具迷惑性：词法层其余规则（跨行/空名）全部生效，唯 `\`` 落 else。
修复：显式 `i + 1 < src.length && src[i + 1] == '\\`'`。教训：复用既有 helper 前核对参数语义。

另一坑：daemon 增量编译把 `compileKotlin` 判 up-to-date 而 classes 未刷新（`--rerun-tasks` 才重编）——
诊断「改动未生效」时先 `--rerun-tasks` 再怀疑代码。

## 四、验收（BEFORE → AFTER)

BEFORE（修复前 CLI check):

```
`x\ny`(a: Nat) 跨行名      → E-LEX: 反引号标识符不能跨行 ×4（错误恢复连报）
`` `` 空反引号              → 静默合法（空名 IDENT,无错误）  ← 比「不能跨行」更隐蔽
`\\`(a: Nat)(3 反引号）     → 通过但名字 = 单字符反斜杠（非反引号）
`foo` vs foo 同声明         → E-DUP-DECL（B3 既有成立）
`fghjk)(*&^%$#` / 中文 / `set pairing` → 通过（既有成立）
```

AFTER（10 例，BacktickIdentTest):

1. 结构字符齐特名声明+调用通过；2. CJK 混杂名通过；3. `` ` `` 与 `` `  `` 两名并存不冲突（词法区分 + 语义无

10. `` `a` ``×2 同名 E-DUP-DECL。

## 五、纪律与后果

- 词法错误通道由「一律 E-LEX」细分为「默认 E-LEX + 特定码」:LexError 加默认参数字段，`toDiag()` 用之。
  既有 3 处 LexError(不认识字符/字符串未闭合/反引号未闭合）零变更。
- LexerTest 既有「不能跨行」诊断用例：本 ADR 前 lex("``")类用例无冲突——跨行诊断用例本就不存在
  于断言层（BEFORE 探针手工复现），故无既有测试需改造；若发现存量用例断言旧行为，按规格变更强制改造。
- 后果：反引号名可含任意字符后，IDE/补全侧（尚未建设）与 glossary 渲染需注意名字不再「可读」；
  token 跨行使单 token 诊断行号 = 起始行（与多行字符串口径一致）。
