# ADR-65: LSP 语言服务增量约束（P-L0 落簿——用户硬约束，防对话失传）

| 状态 | 口径 |
|---|---|
| 已接受（2026-11-14，t164 大纲立约 + t165 P-L0 落簿） | **用户硬约束**；约束 LSP/语言服务及一切进程内工具消费面 |

## 背景

**用户原话（t164 任务书转述）**：旧工程 LSP **全量重建**导致非常慢，用户明确「**宁愿新工程开发速度慢一点**」也要增量。

**旧工程全量教训溯源（字典点查，D-1 参考式重写口径）**：

> 「核心策略：每次 didOpen/didChange 重新 tokenize + parse + check，缓存 AST 与诊断结果，后续 hover/definition/completion 直接查缓存。」——旧工程 language-service/LspAnalysis.kt 类注释（:17-18；实跑句 analyze() :348-349、core 挂载行号过滤 diagnosticsFor() :494-497）

即**结果级缓存、过程级全量**：每次击键全量重跑词法→语法→语义，且 check 输入每遍重挂 stdlib（用户条目 + core 目录拼接、stdlib 位置整体平移到用户行数之外再靠行号过滤剔除——旧 LspAnalysis.kt analyze() :349 / diagnosticsFor() :494）。结构性结论：**旧 LSP 的慢不是某处实现失误，是架构选择**——事后优化无法挽回，新工程必须在架构层把增量当默认。

**落簿动机（S-3 §2.1）**：任务书引用禁止依赖对话记忆——对话会失传，规范不会。该用户硬约束目前仅存于 t164 任务书（对话层载体），必须落条款，否则失传后无据。

## 候选方案

| 方案 | 形态 | 风险 |
|---|---|---|
| A · 不落簿 | 口头/任务书级载体 | 违 S-3 §2.1；对话失传后约束消失，全量重建在进度压力下回潮 |
| B · 仅 ADR | 理念层记录（documents/idea documents/，记录性「为何如此」） | 约束力弱：理念文档不参与裁决（documents/README 权威等级） |
| **C · ADR + specification 已决事项登记** | 本 ADR（动机 + 溯源）+ specification/README.md 已决事项 D-13（约束行） | 双处维护；落簿成本一次性 |

## 决策（采纳 C）

**1. 约束条款（D-13 落簿内容）——LSP/语言服务分析调度三硬条**：

1. **增量默认**：文档级缓存 + 失效传播是框架**内置结构**（而非事后优化）；分析调度以增量为默认设计。
2. **禁止全量重建架构**：不得引入「每次文档变更即重建全部分析状态」的架构（旧工程 language-service 的「每次 didOpen/didChange 重新 tokenize + parse + check」策略即此类，已否决）。单元级重跑（G0，大纲 §2.2）仅可作**保底路径**，不得作默认设计。
3. **增量正确性以差分台账证明**：增量路径验收 = 全量复跑 vs 增量产物逐字比对（同 jsoncmp/t160-parity 纪律）+ 负例先红；未证明前不得宣称增量收益（无延迟断言——诚实边界，大纲 §9）。

**2. 约束范围（界）**：

- **约束对象**：语言服务的**分析调度层**（缓存/失效/重算粒度）与一切进程内工具消费面。
- **不约束编译器内核**：`compileFrontend` 保持纯函数全量语义（S-1 层间总契约 3：相同输入必产相同输出）——单元级"全量"是编译契约而非违例；LSP 的增量在**调度层**兑现（输入哈希缓存、栅栏复用、粒度分级 G0/G1/G2，大纲 §2.2）。
- **例外通道**：保底路径例外仅允许（a）度量数据证明增量路径不可行时；（b）语义层增量（G1/G2）差分证明前的过渡期——两种例外均须以 ADR 显式登记，不得静默回退全量。

**3. 与既有纪律的接法**：本约束不替代 N-SEV-BLOCK / 差分台账 / 负例先红等既有纪律，是其上游约束（验收时任何「为简单而全量」的辩护以本约束判负）。

## 后果

- **正面**：约束可被任务书/验收引用（条款编号 D-13 / 本 ADR）；防回潮——新功能压力下的全量重建诱惑有了明确判据。
- **代价**：开发速度受影响（用户已认可方向：「宁愿开发速度慢一点」）；增量复杂度前置（P-L1~P-L4 前置件，大纲 §10）。
- **首个兑现件**：t165 P-L1 公共挂载入口（编译入口通道统一，消除嵌入方手工复刻装配的漂移面）——本 ADR 约束的是调度层，P-L1 是调度层之下的**通道前置**；增量调度本体（栅栏/缓存/失效）随 LSP V1 落地。
