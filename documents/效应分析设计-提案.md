## 1 可转换矩阵形式化（R-25.3 口径：行=源、列=靶）

源/靶四视图格（t98 `viewKindOf`）：**PLAIN**（T）、**MUT**（@mut T）、**REF**（@ref T）、**REFMUT**（@ref @mut T）。
格值三分类：**引用（共享同一对象）**、**复制（深拷隔离）**、**不可转换（E-TYPE-MISMATCH 拒格）**。

### 1.1 全 16 格判定表（行=源 got，列=靶 want）

| 源＼靶 | PLAIN | MUT | REF | REFMUT |
|---|---|---|---|---|
| **PLAIN** | **引用**（:155 共享） | **拒（R-28）**（旧 :98 造格深拷——已废止，迁移 toMutableList(…) 构造族） | **引用**（:150 不拷） | **拒（R-28）**（源只读供不出可写） |
| **MUT** | **复制**（:91 降级深拷——R-29 落 D-DEEP-COPY 补注） | **复制**（:105 深拷——R-29 落 D-DEEP-COPY 补注） | **引用**（:121 只读视图） | **引用**（:114 别名共享） |
| **REF** | **拒（R-28）**（旧 :162 不可变引用转非引用深拷——已废止，迁移 copy(…)） | **拒（R-28）**（旧解引用造格——已废止） | **引用**（:127 引用同一值） | **拒（R-28）**（只读引用供不出可写） |
| **REFMUT** | **拒（R-28）**（旧 REF→PLAIN 深拷——已废止） | **拒（R-28）**（旧造格深拷——已废止） | **引用**（:137 只读视图） | **引用**（:132 引用同一值） |

**R-28（t150）修订**：5 格隐式深拷废止改拒（PLAIN→MUT / REF→PLAIN / REF→MUT / REFMUT→PLAIN / REFMUT→MUT）——拒格落 E-TYPE-MISMATCH（既有码族）+ 消息含迁移指引（copy(…) 取不可变副本 / toMutableList(…) 构造可变副本）；7 共享格（含 MUT→REF / MUT→REFMUT / REF→REF / REFMUT→REF / REFMUT→REFMUT）零回归；MUT→PLAIN / MUT→MUT 复制格保持并落 R-29 D-DEEP-COPY 补注（非 E 级、不拦）。判定树见下一行（TypeInfer.copyDispatch 三态）。

R-28 判定树（与 TypeInfer.kt `copyDispatch` 三态逐字对应）：`want REF → 共享`；`want REFMUT → 源∈{MUT,REFMUT} ? 共享 : 拒`；`want PLAIN → 源=PLAIN ? 共享 : 源=MUT ? 复制（R-29 补注） : 拒`；`want MUT → 源=MUT ? 复制（R-29 补注） : 拒`。拒格一律落 E-TYPE-MISMATCH + 迁移指引（r28Report）；复制格落 D-DEEP-COPY 补注（deepCopyNote，R-29）。

### 1.2 元素层（R-14 容器实参位）
`List[@mut T] → List[T]` 这类**容器泛型实参位**按元数对齐成对递归（elementDecisions）；共享路径（top=引用）零下钻——整体共享则元素随享；联合别名展开形态（want = `Nil | Cons[Nat]`）取与源元数相符的变体位，**头名/元数不齐 → 零元素结论（保守地板）**——本提案 §2 的「含糊一律拒」与该纪律同源。

### 1.3 与运行时的接位（前端类型层 ⇄ 后端）
前端只做**类型层判定 + HIR 留痕**（R2 §三 / 根文档 N3 裁定）：`deep=true` 时后端按 D-REF-DISPATCH 旁注执行深拷；`deep=false`（引用格）后端共享指针。深拷贝运行时接口见 §4。

## 2 同域修改=纯：源头追踪规则（R-26.4）

### 2.0 总则
写效应的**纯度归属**取决于被写对象的**源头**（origin），而非其视图标签：
- **局部声明域（local）**：对象由本函数的声明帧创建（构造器调用结果、`mutableListOf(...)` 族构造结果、本函数内字面量、**复制格代入**——降级深拷产生的新对象、形参值参位 R-20 传入的拷贝）；
- **外域（outer）**：调用方实参（**借入通道**：`@ref` want 形参 / `&` 借用实参）、祖先帧捕获的变量、模块/全局可变状态、挂载快照的可写别名。

**R-26.4 判据**（队长裁）：写**外域** = 效应逃逸 ⇒ 拦；写**局部声明域** = 纯（效应随调用结束而灭）。

### 2.1 规则 R1：接收者来源判定
`self`/接收者的来源按**帧序溯源**（既有 SymbolTable 帧链——零新载体）：

| 接收者形态 | 来源判定 | 依据 |
|---|---|---|
| 构造器/构造族调用结果（`Cell(0)`/`mutableListOf(1,2,3)`） | **局部**（调用点产品在本帧） | §0.3 R-20；t146 构造族形态 |
| 复制格代入（want 非 ref ⇒ 深拷照门） | **局部**（深拷产生新对象） | §1.1 复制格；根文档 :91/:98/:105 |
| 借入形参（`f(xs: @ref @mut List[Nat])` / `f(&xs)`） | **外域**（实参属调用方帧） | R-21；Elaborator.kt:3453-3481 |
| 祖先帧 `@mut var`（闭包捕获） | **外域**（捕获即可逃逸——R-26.4 拦面） | Elaborator.kt:4116-4123（E-MUT-CAPTURE 同判据） |
| 模块挂载/全局可写别名 | **外域** | R-22 限定通道；模块面只读快照 |

### 2.2 规则 R2：@mut @ref 借入通道（拦）
形参 want 持 `@ref @mut`（或 `&` 借用实参）⇒ 该通道的写直透调用方对象——**无论调用方传的是局部还是外域**（callee 无法证明，含糊即外域）。接位：`E-IMPURE-REQUIRED` 闸面（callee 体内 @mut 方法/字段写经借入通道）——**不是新码**，是把 t141「接收者 @mut ⇒ impure」的判据收窄为「接收者**外域** ⇒ impure」后，借入通道自然全落外域。

### 2.3 规则 R3：引用语义别名传播
`@ref var view = o` 后，`view` 的写入（经 REFMUT/可写路径）等价于 `o` 的写入（根文档 :114-117 实证：`b.n = 1; print(a.n)` 输出 1）。**溯源深度 = 一层**（直接别名）；多层别名链（`@ref var c = b` 其中 b 已是别名）按「别名→原源」逐层回溯到首个非 @ref 声明——回溯不动（类型层不可判，如经联合别名/模块面）⇒ **含糊拒**（外域处理）。

### 2.4 规则 R4：闭包捕获逃逸（拦）
被闭包捕获的局部 `@mut` 变量，若该闭包**可能逃逸**（被返回 / 存入外域字段 / 传入外域通道），其写效应跨调用存活 ⇒ 拦。**保守地板口径**：当前 R-21 裁定「逃逸分析不搞」⇒ 捕获即按可逃逸处理（R-26.4 「被捕获可逃逸的局部=拦」与之逐字一致）——与 S6 「让它逃」不冲突（见 §3.4 论证）。仅在本函数内调用、不逃逸的闭包写捕获变量 → 由 E-MUT-CAPTURE 既有三路出路承接（形参化 / `val` 快照 / @impure），**不新开面**。

### 2.5 规则 R5：含糊一律拒（保守地板）
所有源头不可判定的形态一律按**外域**处理：元素型 synthetic 回退（零参 `mutableListOf()` 的 `?T`）、联合别名展开头名不齐、跨模块引用、退化轮未决元变量。与 §1.2 的「零元素结论（保守）」、t141「深拷照门」同一纪律血统——**宁可误拦，不可漏放**（漏放 = 同输入异输出，R-07）。

### 2.6 参数通道的 R-27 口径（队长裁决口径）

函数参数的形式化一律按 **R-27**：

| 槽位 | 内容 | 效应归属（源头追踪） |
|---|---|---|
| `[]` 理论参数槽 | **类型参数** T/U… + **命题参数** @q（形参位声明） | 类型参数按值通道：实参位 want 非 ref ⇒ 复制格 ⇒ 来源局部（§2.1）；@q 命题参数为**编译期命题**，零运行时对象 ⇒ 源头追踪**不触及** |
| `<>` 实际命题槽 | 调用位供给的实际命题（witness<tagged<7>>() 形态） | 编译期弥散面（上下文系统 t148 R-26.1 通路）；零运行时写效应 ⇒ 不入效应矩阵 |
| 值形参（e : T） | R-20 值参形态 | want 非 ref ⇒ 深拷照门 ⇒ 局部（§1.1 复制格） |
| 借入形参（xs : @ref @mut T / &x） | R-21 借用通道 | **外域**（R-26.4 拦面，§2.2） |

推论：**别名传播（R3）只可能经引用通道发生**——理论槽（无论类型还是命题参数）不产生运行时别名，捕获逃逸（R4）只发生在值域（@mut var 帧链），命题槽的「逃逸」属上下文弥散域（不列效应）。 mutableListOf[T](@list e : T) 的 T 是理论参数槽，e 是值形参变长位（@list）——变长吸收的实参逐一 unify（首解为准，t46/t146）⇒ 元素层拷贝判定按 §1.2 下钻。

## 3 与既有闸的接位（零新闸码）

### 3.1 E-IMPURE-REQUIRED（t141 → 精度升级）
现状（Elaborator.kt:4139-4145）：`node.nid in mutMethodCalls && 调用帧链纯 && 被调侧未按声明 impure` ⇒ 拦。
升级：判据从「接收者 @mut/@mutable」改为「接收者来源 ∈ 外域」——局部接收者（§2.1 前两行）放行，借入/捕获/外域接收者保留拦截。t141 注释「V1 一刀：判据不看实参视图（深拷照门）」的**深拷照门**正是此升级的预留口：值参形态（want 非 ref）已深拷 ⇒ 来源局部。

### 3.2 E-IMPURE-CALL / 三路放行（不变）
纯度闸主体（:4124-4135）不动：调用方非纯放行 / unchecked 单语句豁免 / Γ⊢`pure<f>` 供给。效应升级只改「什么算 impure」的输入（callee 声明口径 + 接收者来源），不改闸结构。

### 3.3 E-MUT-CAPTURE（互补不重）
E-MUT-CAPTURE 判「纯函数访问捕获的外层可变变量」——**捕获即外域**（§2.1 倒数第二行）。源头追踪的「同域=纯」只覆盖**本帧创建**的对象，两者判据域不相交：捕获的必外域，本帧的必不捕获。**无须合并、无须去重**。

### 3.4 R-21「让它逃」与本提案不冲突的论证
S6 裁「逃逸分析不搞、借用让它逃」是对**借用实参逃逸到 callee 之外**的放行；本提案 §2.2 拦的是** callee 经借入通道写外域**——维度不同：

| | R-21（S6） | R-26.4（本提案） |
|---|---|---|
| 对象 | 借用实参的**逃逸去向** | 借入通道的**写效应归属** |
| 裁定 | 不分析、让它逃（调用方自保） | 写 = 效应 ⇒ 归外域 ⇒ 拦（callee 侧 E-IMPURE-REQUIRED） |
| 交叠 | 借用实参传给 f 后 f 内部**不写**只读/再传 —— 两口径都放行 | f 内部**写**借入通道 —— R-21 不裁写，R-26.4 拦 |

S6 落地纪要已实证该机制的现状形态：「callee 体内 @mut 方法调用 ⇒ callee 推导 impure ⇒ 闭包单调传播使调用方推导 impure」——升级只是把「@mut 方法」收窄为「@mut 方法 + 外域接收者」。**结论：无冲突，R-21 的裁不被推翻。**

### 3.5 R-17/R-18/R-20 接位
- **R-17/R-18**：@mut 方法调用须调用方 @impure/unchecked；方法体写接收者无罪（R-18.2——self 为自带形参）。升级后：self 来源局部时**亦无罪于纯度闸**（E-IMPURE-REQUIRED 放行），R-18.2 精神延伸到构造族局部；
- **R-20 值参形态**：形参 want 非 ref ⇒ 复制格 ⇒ 来源局部（§1.1）——值参即「同域化」通道，与「同域修改=纯」天然贴合；零参 synthetic（`?T`）按 R5 含糊处理（仅元素层判保守，顶层来源仍为构造点局部）。
- **R-27 参数口径**：效应面只消费值域通道（值参/借入/别名/捕获）；理论参数槽（[]：类型 T + 命题 @q）与实际命题槽（<>）零运行时写效应（§2.6）——纯度判据**不读**参数槽形式，只读写效应的源头归属。

## 9 风险与诚实边界

1. **保守地板的误伤面**：R5「含糊一律拒」会拦住一批语义上可能纯的形态（如多层别名写局部）——这是 R-26.4 字面口径的直接代价，判别性样本（§5 行 1）与误伤候选（§5 行 7 多层别名）已同表列明。**不做静默放行**。
2. **t141 现状口径不动**：本件只设计升级路径，t141 保守闸（@mut 接收者 ⇒ impure）在实现件落地前逐字保持——`xs.add` 局部场景今日仍拦（特性巡礼样本已标 @impure 适配）。
3. **深拷贝不实现**：前端无运行时层（R2 N3 裁定）——§4 是 R4 需求登记，不是实现承诺；CoW 为候选。
4. **零码改、零代裁**：本件不落任何 main 树代码、不裁决 OQ-1..10；落地须另派实现件（§6），验收同 t146 五段口径。
5. **旧工程仅作字典**：根文档 :89-163 是口径来源（§1），旧 wiki 的停机/自动降级（D-AUTO-IMPURE）等条款不在本提案范围（t93 审计已判 ❌/🔱，未复刻）。

## 10 落地批史（t151 实现件——2026-11-13）

**实现态**：S1 接收者来源溯源 + S2 E-IMPURE-REQUIRED 判据收窄已落 main 树（Elaborator / SymbolTable / TypeInfer 三件），验收按五段机械证据（判别性探针 / 68 门 vs t122n 死冻锚 / 精确差分 vs t150gate / stdlib 侧 / 确定性 + 脚本门）。

**登记面（局部来源 = 同域修改=纯的判据原料）**：
- var 声明位：复制格代入（R-28 矩阵 want 非 ref × 源 @mut 视图 = 深拷产生新对象）⇒ 局部；其余按初值来源（构造点/函数调用产品、本函数内字面量、同域名一层回溯 R3）；

- 帧序比较（OQ-1 零 schema 载体）：`SymbolTable.bindingInCurrentFun`——名绑定在 innermost FUNCTION/SCRIPT_TOP 及其内部块帧内 ⇒ 局部；祖先帧（捕获 = 外域，R4）与全局层 false。

**判据收窄口径**：E-IMPURE-REQUIRED 的 mutMethodCalls 注册位（方法糖注解位 + 限定 ext 调位 ×2）加 `!receiverOriginIsLocal(args.first())` 过滤——局部来源接收者不入闸 ⇒ 种子（D-PURITY-INFERRED 引用可变调用）与 E-IMPURE-REQUIRED 同时收窄（单一 set，无第二集合）。闸消费面零改。

**裁决记录（实现与设计文本的偏差，逐条登记）**：
1. **§2.6「值形参 = 局部」→ 实现按 R5 保守地板收紧为「形参一律外域」**：@mut 形参通道可经 `&` 借用实参翻为借入通道（R2；t128 样本 `借用不绕过纯度门` 的口径延续——callee 无法证明调用方不借用 ⇒ 含糊一律拒）。代价：值参形态接收者仍保守误拦（精确逃逸分析 = 范围外，§6 S5 后版）；判别性样本（局部构造族 var）不受影响。
