## 发现登记（语言面，未动主码）

### F1【工效/推导面】union 元素列表：var 标注不回传嵌套构造子

- **现象**：`var xs: List[U] = Cons(A, Cons(B, Nil))`（U 为零字段 struct 联合）→ 内层 `Cons` 落
  `E-TYPE-MISMATCH: 构造子 Cons 实参 Cons[B] 与字段 Nil | Cons[A] 不符`。构造子类型参数 T 从 head 实参
  推导为**具体成员类型**（A），var 的 `List[U]` 标注不参与嵌套构造子的回填；混合两元素即失败
  （单元素 + Nil 尾可通过——Nil 同时属于两边）。
- **最小复现**（已 CLI 实测落 E-TYPE-MISMATCH 于 10:23）：
```
struct Nil
struct Cons[T](head: T, tail: List[T])
type List[T] = Nil | Cons[T]
struct A
struct B
type U = A | B

@impure
fun main() {
    var xs: List[U] = Cons(A, Cons(B, Nil))
}
```
- **规避法（本任务样本已用）**：逐层显式角表类型实参 `Cons<OrderEvent>(RequestPay, Cons<OrderEvent>(RequestShip, …))`——
  head 实参走「成员→联合单向拓宽」，角表钉住 T。
- **影响面**：数据建模常见形态（事件流/状态序列/可选值列表）在免角表写法下不可用；属推导面工效缺口，非健全性破口
  （错的是写法被拒，不是坏写法被放行）。
- **归属建议**：S2 推导链后续裁（构造子回填是否吃 var 标注/期望类型），非本任务范围。

### F2【语法一致性】调用位类型实参括号不一致（类型位 [] vs 调用位 <>）

- **现象**：`Cons[U](A, …)`（方括号调用形态，与类型位的 `List[U]` 同款）落 `E-SYNTAX: 期望表达式 … 跳过符号 '['`；
  合法形态只有尖括号 `Cons<U>(…)`（既有绿样本仅 `Channel<Nat>(1)` 一例用到）。
- **最小复现**（已 CLI 实测落 E-SYNTAX 于 10:27）：见 F1 复现改 `Cons[U](A, Cons[U](B, Nil))`。
- **影响面**：类型位/调用位两套括号，新写程序易踩（本人即踩：先试 [] 后试 <> 才过）；建议后续语面统一或补 [] 别名。
- **归属建议**：语法面裁决项，非本任务范围。
