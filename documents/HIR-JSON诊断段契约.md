# HIR JSON 的 diagnostics 契约（实测，2026-11-09）

## 事实

`compile` 产出的 `sublimation/hir@v3` JSON **包含 `diagnostics` 段**，且**全部严重度**都在内：

| severity | 基线 68 样本出现次数 |
|---|---|
| `error` | 10 |
| `supplement` | 59 |
| `hint` | 3 |
| `warn` | 2 |

覆盖 **26 个样本文件**。

## 由此得出的三条纪律

1. **新增任何诊断码（含 W/H/D 族）都会改变受影响的样本 JSON**——比对前先问「这条新诊断会不会落到某样本上」；
2. 「提示不影响产物」这句话**在本项目是错的**，不许再出现在任务书里（我 2026-11-09 犯过这个错，见 ADR-49 更正）；
3. 中间态允许出现 JSON diff，但必须满足：**可归因**（说得出是哪条任务引入的）+ **有闭合任务**（说得出哪条任务会让它归零）。
