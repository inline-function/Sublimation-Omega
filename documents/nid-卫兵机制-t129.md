# nid 卫兵机制（t129 清账件 4）

## 方案（半页）

**问题**：nid 纪律（ADR-14「单一分配源」/ D-14 族 3 起事故——壳复用零分配、虚拟登记 zero-hit、etype 跨轮幂等）
长期靠口头与 review 把关，无机制护栏。

**不变量族**（先实证后定型）：
- **N1 分配唯一**：恒等意义上**不同节点实例**持不同 nid（共享实例重访——快照/符号回指——不算违例）。
  结构根：NodeIdSource（SymbolTable:528）单计数器单调 alloc；违例 ⇔ 出现了第二个计数器或身份复制 bug。
- **N3 双编译确定性**：同一输入两次全流水线（parse → compile → emit）产**逐字节相同** JSON。
  覆盖 nid 序列确定性 + 整体重放确定性（SAME 门的单元级缩影）。
- **N2（否决为护栏）**：最终树林 nid 稠密——**实测不成立**（list 样本 1485 用 / 4716 分配：R 轮重推导的分配 churn
  属既有基线，非违例）。作为「消费泄漏」信号只在优化件再评估，不进卫兵。

**选型与侵入面评估**：

| 形态 | 侵入面 | 结论 |
|---|---|---|
| 构建期断言（main 内 freshNid/节点 init 检查） | 全编译路径 O(n) 哈希集 + 诊断语义风险 + perf 面改 | **拒**（生产路径加可失败断言，非保守） |
| 测试期钩子（test 源内 NidGuard + 测件） | main 零改动；Java 反射恒等遍历（IdentityHashMap 防快照重访误报） | **采纳（最保守形态）** |
| JSON 产物侧密度断言 | 对 68 产物 walk | **不采纳**（N2 实测不成立；密度信号语义错——见上） |

**实现**：`frontend/src/test/.../NidGuard.kt`（object，零 main 面）+ `T129NidGuardTest`：
- 内联语料（零借用 / 借用 / 局部 fun 注解 / unchecked / 泛型 / 联合别名）逐样本跑 N1 + N3；
- diff-pairs 借用 fixture 同跑（近期 nid 消费热点面）。

**实测基线（本件收口）**：N1 于全部受测样本成立（见测件）；N3 双编译逐字同成立。若未来引入第二计数器或
非确定分配，N1/N3 测件红——机制化达成（F1 blocker 契约由测件承接，不再靠口头）。
